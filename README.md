# AI Project Executor

AI Project Executor - внутреннее веб-приложение для управления проектами и автоматического исполнения задач ИИ-агентом по расписанию. Система ориентирована на работу 1С-консультанта: проекты ведутся в едином интерфейсе, задачи планируются по датам, а агент в назначенное время готовит рабочие документы и отправляет результат в Telegram.

## Назначение

Приложение помогает держать под контролем проектную документацию по внедрениям 1С: уставы проектов, технические задания, коммерческие предложения, протоколы, статусные отчёты, уведомления и комбинированные документы. Основной сценарий - заранее поставить задачу с датой, добавить контекст в чат задачи и получить готовый документ без ручного запуска.

## Основные возможности

- Ведение проектов с клиентом, описанием и перечнем конфигураций 1С.
- Создание задач с типом документа, датой исполнения, режимом работы и повторяющимся расписанием.
- Двухнедельный дашборд в формате календарной доски: даты по строкам, проекты по колонкам, задачи внутри ячеек.
- Отдельный раздел "Задачи и проекты" для общего управления проектами и задачами.
- Фильтрация задач по статусу выполнения, проекту, периоду создания и периоду задачи.
- Сортировка списка задач по статусу, названию, проекту, типу документа, датам и режиму.
- Удаление проектов и задач из интерфейса.
- Хронологический чат задачи как источник дополнительного контекста для ИИ-агента.
- История исполнений задачи с результатами, статусами, ошибками и файлами.
- Журнал исполнений по всем проектам с фильтрами и быстрым доступом к результатам.
- Настройки интеграций с Telegram и Anthropic без отображения секретных токенов в открытом виде.

## Дашборд

Главный экран показывает ближайший рабочий горизонт на две недели. Каждая строка соответствует дате, каждая колонка - проекту. Задачи отображаются в ячейках по дате и проекту, что позволяет быстро увидеть загрузку, пробелы в плане и ближайшие автоматические исполнения.

Дашборд поддерживает переключение по неделям, подсветку текущего дня и визуальное различение проектов. Из пустой ячейки можно перейти к созданию задачи для выбранного проекта и даты.

## Управление проектами и задачами

Раздел "Задачи и проекты" объединяет операционные действия:

- создание нового проекта;
- создание новой задачи;
- просмотр списка проектов;
- просмотр общего списка задач;
- фильтрация невыполненных, выполненных или всех задач;
- фильтрация по конкретному проекту;
- фильтрация по периоду создания задачи;
- фильтрация по периоду запланированного исполнения;
- сортировка по столбцам таблицы;
- удаление проекта или отдельной задачи.

Карточка проекта показывает название, клиента, конфигурации и прогресс по задачам. Таблица задач показывает статус, название, проект, тип документа, дату задачи, дату создания и режим исполнения.

## Карточка проекта

Карточка проекта содержит ключевую информацию по клиенту и проектному контуру:

- название проекта;
- клиент;
- конфигурации и системы, связанные с проектом;
- описание проекта;
- список задач проекта;
- прогресс выполнения задач;
- быстрые действия по запуску, редактированию и удалению задач.

## Карточка задачи

Карточка задачи разделена на две рабочие зоны. Слева отображаются параметры задачи и история исполнений. Справа расположен чат задачи - контекст, который агент читает перед генерацией документа.

Чат задачи используется для уточнений, требований, вводных данных, контактных лиц, бюджетов, рисков, решений совещаний и любых деталей, которые должны попасть в будущий документ.

## Типы документов

Система поддерживает несколько типов выходных материалов:

- **CHARTER** - устав проекта.
- **TZ** - техническое задание на внедрение или доработку 1С.
- **KP** - коммерческое предложение.
- **REPORT** - статусный отчёт по проекту.
- **PROTOCOL** - протокол моделирования или рабочего совещания.
- **NOTIFICATION** - короткое Telegram-уведомление без DOCX-файла.
- **COMBINED** - документ DOCX и отдельный текстовый анонс для Telegram.

Для каждого типа документа используется специализированный промпт, учитывающий структуру, стиль и обязательные разделы.

## AI-агент

ИИ-агент собирает контекст из проекта, всех задач проекта, текущей задачи и чата задачи. На основе этого контекста он генерирует документ в деловом стиле, ориентированном на проекты внедрения 1С.

Агент учитывает:

- название и клиента проекта;
- конфигурации 1С;
- описание проекта;
- полный список задач проекта и их статусы;
- параметры текущей задачи;
- сообщения из чата задачи;
- тип требуемого документа;
- режим исполнения задачи.

Если данных недостаточно, агент помечает недостающие сведения как требующие уточнения, чтобы не подменять реальные проектные данные выдуманными.

## Автоматическое исполнение

Задачи могут исполняться по назначенной дате или по повторяющемуся расписанию. Планировщик регулярно проверяет задачи, которые готовы к запуску, берёт их в работу и запускает генерацию документа.

Система защищает задачи от дублей при параллельной работе нескольких экземпляров приложения: задача переводится в работу атомарно, и второй исполнитель не сможет забрать её повторно.

Для повторяющихся задач после успешного исполнения вычисляется следующая дата запуска, а задача возвращается в очередь ожидания.

## Режимы выполнения

Поддерживаются два режима:

- **AUTO** - агент генерирует документ и сразу отправляет результат в Telegram.
- **CONFIRM** - агент генерирует документ, отправляет превью в Telegram и ждёт подтверждения.

В режиме подтверждения пользователь может принять результат или отправить задачу на доработку. При отклонении задача возвращается в ожидание, а пользователь может добавить правки в чат задачи и запустить генерацию заново.

## Telegram-интеграция

Telegram используется как канал доставки результатов и уведомлений. Система умеет:

- отправлять готовые DOCX-файлы;
- отправлять короткие уведомления без файла;
- отправлять превью документа на подтверждение;
- показывать inline-кнопки подтверждения и отклонения;
- отправлять алерты при ошибках выполнения;
- автоматически определять чат после сообщения пользователя боту.

Для пользователя не требуется ручной ввод Chat ID: достаточно указать токен бота, написать любое сообщение этому боту и запустить поиск чата в настройках приложения.

## DOCX-документы

Для документов, требующих файла, результат ИИ-агента преобразуется в DOCX. Поддерживается базовая структура делового документа:

- заголовки;
- подразделы;
- списки;
- таблицы;
- выделение текста;
- стандартное оформление листа;
- человекочитаемое имя файла.

Файлы сохраняются как результаты конкретных исполнений и доступны из истории задачи и журнала исполнений.

## Статусы задач

Задачи проходят несколько состояний:

- **PENDING** - ожидает запуска.
- **RUNNING** - выполняется.
- **WAITING_APPROVAL** - ожидает подтверждения.
- **DONE** - выполнена.
- **FAILED** - завершилась с ошибкой.

Статусы отображаются на дашборде, в таблицах задач, в карточке задачи и в журнале исполнений.

## Журнал исполнений

Журнал исполнений показывает историю работы агента по всем задачам. В нём можно увидеть:

- дату запуска;
- задачу;
- проект;
- статус исполнения;
- длительность;
- наличие файла;
- текст ошибки при сбое.

Журнал помогает быстро находить неудачные генерации, проверять историю отправок и скачивать готовые документы.

## Ошибки и повторные попытки

Если генерация или внешняя интеграция завершается ошибкой, система фиксирует её в исполнении и переводит задачу в соответствующий статус. Для ошибок API предусмотрены повторные попытки. При критическом сбое в Telegram отправляется алерт с названием задачи, проектом, текстом ошибки и временем возникновения.

## Сценарии использования

### Подготовка устава проекта

Консультант создаёт проект, добавляет задачу "Написать Устав проекта", указывает дату исполнения и заносит в чат задачи вводные: контактных лиц, бюджет, сроки, риски и участников. В назначенное время агент формирует устав проекта и отправляет его в Telegram.

### Техническое задание по интеграции

В задаче фиксируются направления обмена, системы-участники, объекты 1С и особенности API. Агент формирует техническое задание со структурой AS-IS, TO-BE, функциональными требованиями, объектами 1С, интеграциями и оценкой трудозатрат.

### Еженедельный статусный отчёт

Повторяющаяся задача запускается по расписанию и формирует статусный отчёт на основе задач проекта и комментариев в чате. Такой сценарий подходит для регулярной проектной отчётности.

### Подтверждение перед отправкой

Для задач в режиме CONFIRM агент сначала отправляет превью документа в Telegram. Пользователь может подтвердить отправку файла или отклонить результат, добавить правки в чат задачи и повторить генерацию.

## Для кого предназначено

Приложение рассчитано на небольшую внутреннюю команду из 1-3 пользователей, которые ведут проекты внедрения 1С и регулярно готовят проектную документацию. Основной пользователь - консультант или руководитель проекта, которому важно быстро формировать документы на основе накопленного контекста.

## Границы продукта

AI Project Executor не заменяет полноценную корпоративную CRM или ERP. Это рабочий инструмент для планирования проектных задач, генерации документов и доставки результатов через Telegram. Главный акцент сделан на автоматизацию повторяемой проектной документации, а не на сложные продажи, бухгалтерию или управление ресурсами.
